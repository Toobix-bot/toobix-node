## Kurzdefinition

**TOOBIX ist ein experimentelles Open-Source-Projekt, das Bedarfe, Angebote, vorhandene Ressourcen und reale Wirkung verständlicher miteinander verbinden will.**

Es ist derzeit **kein produktives Hilfsnetzwerk**, keine Behörde, kein medizinischer oder rechtlicher Dienst und keine Instanz, die den Wert von Menschen bewertet.

## Das Problem, das TOOBIX untersucht

Oft existieren gleichzeitig:

- ein Bedarf,
- eine passende Ressource,
- Menschen oder Organisationen, die helfen können,
- und trotzdem keine funktionierende Verbindung zwischen ihnen.

TOOBIX untersucht deshalb vier Fragen:

1. **MAP:** Was existiert bereits?
2. **SENSE:** Wo besteht Bedarf, Druck oder eine Versorgungslücke?
3. **CONNECT:** Welche vorhandenen Ressourcen könnten sinnvoll verbunden werden?
4. **LEARN:** Hat eine reale Handlung tatsächlich geholfen?

## Kein Anspruch auf Einzigartigkeit

🟢 Viele Teilprobleme werden bereits von guten bestehenden Systemen bearbeitet: Ressourcenverzeichnisse, humanitäre Datenplattformen, Freiwilligenvermittlung, offene Standards und Krisenkarten.

🟣 Die TOOBIX-Hypothese lautet, dass eine zusätzliche **Übersetzungs- und Orchestrierungsschicht** zwischen solchen Systemen nützlich sein könnte. Diese Hypothese muss an realen Abläufen geprüft werden.

## Resource Graph

Ein mögliches Zielmodell ist kein Verzeichnis nur von Personen, sondern ein Graph aus verschiedenen Entitäten und Beziehungen:

```text
Mensch ↔ Need / Offer
   ↕
Gruppe / NGO / öffentlicher Dienst
   ↕
Ort / Raum / Infrastruktur
   ↕
Wissen / Daten / digitales Angebot
   ↕
reale Handlung und Wirkung
```

Das System soll möglichst zuerst prüfen, **welche bestehende Hilfe bereits zuständig und geeignet ist**, bevor neue private Hilfe organisiert wird.

## Was TOOBIX bereits öffentlich anbietet

- eine Verfassung und Grenzen gegen Menschen-Scoring und Zwang,
- JSON-Schemas für Entity, Need, Offer, Match und Impact Event,
- die Reality Bridge,
- ein experimentelles LIFE-Impact-Modell,
- synthetische Testdaten und Missbrauchstests,
- diesen offenen Knowledge Node.

## Was TOOBIX gerade braucht

- Gegenbeispiele und Kritik,
- zuverlässige Quellen,
- Hinweise auf bestehende Systeme,
- Tests mit synthetischen oder risikoarmen Szenarien,
- Menschen, die Teile übernehmen, verbessern oder eigene Nodes daraus bauen.
